# Apple Web Design Science

Version: 0.1.0

This package contains the first version of a reusable AI-agent skill for
building Apple-inspired web applications.

It is designed around:
- iOS 26 / Liquid Glass language
- macOS Tahoe 26 language
- Apple HIG principles
- design science / HCI heuristics
- WCAG 2.2 web accessibility
- user-supplied screenshots
- user-supplied Liquid Glass implementation research

The skill is intentionally modular so additional screenshot batches can be
used to refine it.

Files:
- `SKILL.md` — main agent skill
- `REFERENCE_NOTES.md` — visual and implementation observations

The next screenshot batches should be used to improve the existing rules
rather than replace them blindly.
